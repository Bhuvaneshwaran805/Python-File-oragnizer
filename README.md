# Python File Organizer

A Python application that automatically organizes files into folders based on their file extensions.

# Features
- Organizes files by type.
- Supports multiple file extensions.
- Includes a simple graphical interface (GUI) in version 2.
- Skips duplicate filenames.
- Generates an organization report.

# Technologies Used
* Python
* Tkinter
* pathlib
* shutil

# How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:
   
python File organizer.py
""""""""""""""""""""
For the GUI version:
""""""""""""""""""""
python File organizer2.py
